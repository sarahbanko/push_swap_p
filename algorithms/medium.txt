Pseudocódigo:

- Receber os elementos na stack A 
- Definir os índices para cada elemento 
- Calcular aproximadamente a raiz quadrada dos elementos para definir:
    - quantidade de chunks
    - tamanho de cada chunk
- definir inicio do primeiro chunk = 0
- definir o fim do primeiro chunk

Primeira fase: enviando elementos de A -> B

Enquanto existir elementos em A 
- definir os limites do chunk atual
- calcular quantos elementos pertencem ao chunk atual
- enviados_chunk = 0
    enquanto enviados do chunk é menor que a quantidade de elementos no chunk
        Procurar em A:
        - o primeiro elemento do chunk a partir do topo
        - o primeiro elemento do chunk a partir do fundo
        comparar qual deles esta mais proximo
        - se for o topo: rotacionar A até ele chegar no topo
        - se for no fundo: fazer rotação reversa até chegar ao topo de A
        guardar mentalmente o indice desse elemento
Enviar o elemento do topo de A -> B
    - se o índice enviado estiver na metade menor do chunk:
        - rotacionar B uma vez
        - aumentar enviados_chunk
avançar os limites para o próximo chunk
** ao terminar essa fase A esta vazia **

Segunda fase: devolver de B -> A

indice_procurado = maior indice em B
Enquanto B não estiver vazia
- procurar a posição do índice_procurado em B
- verificar se ele esta mais próximo do topo ou fundo
    - se tiver perto do topo: rotacionar B até ele chegar ao topo
    - se não: fazer a rotação reversa em B até ele chegar ao topo
- Envia para A
- diminuir índice procurado em 1
